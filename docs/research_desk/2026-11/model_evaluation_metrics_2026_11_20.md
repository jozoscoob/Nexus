# 분석 모델 평가 지표 — 비교·적용한 방식 전체와 지표 읽는 법 (2026-11-20)

> 대상: G2 참고 범위(가격 밴드)에 비교·적용한 방식 전체 + 기준선, G1 변인 순위. 가격 수준은 싣지 않음(%·점수만).
> 평가 공통 조건: CME 대두유 근월 정산가, **walk-forward 2012~2025**(각 날짜에 그날까지 알 수 있던 정보만으로 범위를 만들고
> h거래일 뒤 실제로 채점), 지평 h = 1·5·20·60거래일(≈1일·1주·1개월·3개월). 같은 내용이 Nexus Terminal의 '모델 평가 보드'에 있다.

## 1. 지표 정의와 읽는 법

| 지표 | 정의 | 좋은 값 | 읽는 법 |
|---|---|---|---|
| **80% 적중(coverage)** | 그날 계산한 P10~P90 범위 안에 h일 뒤 실제 가격이 든 비율 | **80%에 가까움** | 낮으면 범위가 자주 빗나감(과신), 높으면 쓸데없이 넓음(과소신뢰). 수용 범위 75~85% |
| **50% 적중** | P25~P75 범위의 같은 비율 | 50%에 가까움(45~57%) | 화면의 굵은 막대가 정직한지 확인 |
| **위·아래 이탈** | 실제가 P90 위 / P10 아래로 벗어난 비율 | 각 10% | 비대칭 점검. 조달은 **위쪽 이탈**이 비용 |
| **평균 폭** | P90−P10을 현재가 대비 %로(walk-forward 평균) | 적중이 같다면 좁을수록 | 적중률과 함께만 의미 있음 — 폭만 좁은 범위는 쓸모없음 |
| **지금 폭** | 오늘 기준 80% 범위의 폭 | — | 실무자가 화면에서 체감하는 크기 |
| **pinball(분위 손실)** | 분위 q의 예측이 실제 y에서 벗어난 거리를 방향에 따라 q 또는 1−q로 가중한 평균 | 낮을수록 | 적중과 폭을 **하나의 점수**로 묶음. 방식 간 우열 판정의 주지표 |
| **중앙 MAE** | 중앙값(P50)과 실제의 절대 오차(%) | 낮을수록 | 점 예측의 정확도 — 범위 방식은 보조로만 봄 |
| **락박스 적중** | 손대지 않고 남겨 둔 구간(2025 하반기)의 80% 적중 | 80% 근처 | 과적합 점검. 이번 비교에서 이 구간을 이미 봤으므로 **준락박스**로 강등, 2026-11-20부터 전향 기록 |
| **폭 일변동** | 60일 80% 폭이 하루에 1%p 넘게 바뀐 날의 비율 | 낮을수록 | 화면 안정성(매일 다른 폭을 보이면 실무에서 신뢰를 잃음) |
| **스트레스 구간 적중** | 2012 가뭄·2018 미중·2020 팬데믹·2022 러우·2025 구간별 80% 적중 | 80% 근처 | 평시 평균에 묻히는 사건기 성능 |
| CRPS | 예측 분포 전체와 실제의 거리(분위 손실을 모든 분위로 적분) | 낮을수록 | **미산출** — 5분위 근사만 가능해 pinball로 대신함. 분위 모델(챔피언 후보) 단계에서 19분위 근사로 산출 예정 |
| MASE | 점 오차를 naive 예측 오차로 나눈 값 | 1 미만 | **미산출** — 점 예측 모델이 아직 없음(범위 기준선 단계). 기준선 B1(최근값)의 MAE가 같은 역할 |

## 2. G2 참고 범위 — 방식 비교 (80% 구간, walk-forward 2012~2025)

| 방식 | 설명 | 5일 적중 / 폭 / pinball | 20일 | 60일 | 지금 60일 폭 |
|---|---|---|---|---|---|
| B2 경험 분위 250일(이전) | 최근 250일 h일 수익률 분위를 그대로 | 78.2% / 8.2% / 6.18 | 74.5% / 16.6% / 12.87 | **63.5%** / 27.1% / 25.19 | 43.4% |
| B2 경험 분위 120일 | 창만 짧게 | 77.4% / 8.3% / 6.31 | 69.7% / 16.1% / 13.91 | 51.2% / 22.6% / 30.71 | 18.5% |
| EWMA 정규(λ 0.94) | 중심=현재가, 폭=최근 변동성 × √h × 정규 분위 | 79.2% / 8.4% / 6.09 | 77.9% / 16.8% / 12.26 | 75.9% / 29.2% / 22.23 | 30.0% |
| FHS 750일 | 과거 수익률을 당시 변동성으로 표준화한 분위 | 80.1% / 8.6% / 6.14 | 77.5% / 18.0% / 12.62 | 71.8% / 33.9% / 24.11 | 30.1% |
| EWMA+컨포멀(B4 원안) | EWMA 폭 × 최근 250개 실현 점수로 보정한 배수 | 80.1% / 8.7% / 6.14 | 79.4% / 18.2% / 12.51 | 77.5% / 33.6% / 22.19 | **51.0%** |
| **B4a′(적용)** | EWMA, 1·5일 λ 0.94 · 20·60일 λ 0.97, 정규 분위 | 아래 표 | 아래 표 | 76.8% · pinball 최저 | **29.6%** |

B4a′ 지평별(2012년부터 매일 적용 — 화면이 직접 계산하는 값):

| 지평 | 80% 적중 | 50% 적중 | 위 이탈 | 아래 이탈 |
|---|---|---|---|---|
| 1일 | 80.6% | 48.7% | 9.8% | 9.5% |
| 5일 | 78.8% | 49.6% | 10.6% | 10.6% |
| 20일 | 78.8% | 47.5% | 11.4% | 9.8% |
| 60일 | 76.6% | 47.6% | 13.1% | 10.3% |

(패널 재검토의 2012~2025 한정 60일 80% 적중은 76.8%, 이 표는 2026년까지 포함한 76.6%.)

판정 근거: 이전 B2는 60일에서 목표보다 16.5%p 낮고 위 이탈 21%. B4 원안은 적중은 좋지만 지금 폭이 51%로 넓고 폭이 매일 흔들림(60일 겹침 표본 250개는 독립 표본 약 4개). B4a′는 적중(5%p 규칙 이내)·pinball(20·60일 B2 대비 유의한 개선)·안정성(폭 일변동 >1%p 6.7%)을 함께 만족 → **기준선 교체**(챔피언 승격 아님).

읽는 법: B1은 '가격이 그대로'라는 점 예측이라 범위 적중은 0에 가깝고, 중앙 MAE(점 오차)의 하한 역할을 한다. 새 방식은 이 기준선들을
pinball과 적중에서 이겨야 승격 후보가 된다. 기준선 백테스트는 2026-11-19에 락박스 경계 정화(채점일이 락박스에 걸린 예측 제외)를 적용해 다시 계산했다.

## 4. G1 변인 순위

| 단계 | 방법 | 2026-11-19 실행 결과 | 읽는 법 |
|---|---|---|---|
| 선별 | Elastic Net(안정성 선택) | **전 계수 0** → 순위를 피어슨 상관 기준 참고 순위로 강등 | 현재 표본·창에서 선형 선별이 아무 변수도 유지하지 못함 — 순위는 '함께 움직인 정도'일 뿐 인과·예측력 아님 |
| 선행성 | Granger(Bonferroni α/m) | 보수적 보정으로 유의 변수 적음 | 다중검정을 엄격히 막은 결과. 유의하지 않다고 무관한 것은 아님 |
| 이상 신호 | 변수별 기준(표준화 지수·물리 범위) | ENSO ONI 1.8(기준 ±0.5) 등 | 기준 초과 사실만 통지 — 방향 판단은 유사 시기 실측 분포로 |

다음 단계(챔피언 후보): 트리 모델(LightGBM)+SHAP·Permutation 교차, 국소투영(충격 반응), horizon×레짐 분해 — 산출 시 같은 표에 추가한다.

## 5. 남은 평가 과제
1. 롤을 걸친 60일 라벨을 같은 계약 라벨로 재계산(연속 근월 계열의 롤 스프레드 혼입 점검).
2. CRPS(19분위 근사)·Winkler 점수·Diebold-Mariano 검정을 분위 모델 단계에서 추가.
3. 2026-11-20부터 전향 기록(진짜 락박스) — 매일 범위와 실제를 원장에 쌓아 월별로 채점.
