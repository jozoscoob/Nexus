# Claude Code 스킬 5종 설치·검증 프롬프트 검토 (2026-10-22)
> 승인자 요청: 공유된 프롬프트(스킬 5종 설치·연결 검증)를 요약하고, 중복·고유 항목을 나누고,
> Nexus에 필요한 요소의 목적·근거와 보완 방법을 정리해 저장소에 반영. 설치는 실행하지 않았다(아래 §4 사유).
> 사실 확인: npm 레지스트리 조회(2026-10-22) — `skills` 1.7.4, `agent-browser` 0.39.1, `@opengsd/gsd-core` 1.18.0.

## 1. 요약
- **역할**: 스킬 5종(agent-browser·find-skills·design-taste-frontend·mcp-builder·GSD)의 설치·연결 확인 담당.
- **입력**: OS·셸, 기술 스택, 한 문장 목표.
- **4단계**: ①Node ≥ 22.20 확인 + 프로젝트(`.claude/skills`)·전역(`~/.claude/skills`) 설치 여부와 GSD(`~/.claude/commands/gsd-help.md`) 확인
  ②빠진 것만 `npx skills@latest add … --copy`로 설치, GSD는 `npx @opengsd/gsd-core@latest --claude --global`
  ③`.claude/skills`에 4종 존재 + GSD `--help` 버전 출력 확인, agent-browser CLI는 선택 설치(`npm i -g` + 브라우저 다운로드)
  ④초보자용 5줄 이내 설명.
- **제약**: 기존 파일 덮어쓰기·삭제 금지, 중복 설치 금지, `.env` 등 비밀 파일 열람 금지, 원본 스킬 무수정.
- **출력**: 실행 명령 목록, Node 버전, 새로 생긴 파일, 남은 오류. 검증 실패 시 완료 보고 금지(실패 명령·원인·다음 조치).

## 3. 프롬프트 자체의 약점과 보완

| # | 약점 | 영향 | 보완 |
|---|---|---|---|
| 1 | 1단계는 전역 설치도 인정하지만 검증은 프로젝트 `.claude/skills`만 봄 | 전역에만 있으면 "재설치 금지"와 "검증 실패"가 충돌 | 설치 범위를 하나로 정함(Nexus는 프로젝트 범위 — 저장소에 반입) |
| 2 | `@latest`·`npx --yes`로 버전 미고정·원격 코드 자동 실행 | 재현 불가·공급망 위험 | 버전 고정(`skills@1.7.4` 등) + 반입 시 `SOURCE.md`에 저장소·커밋 기록 |
| 3 | GSD 검증이 `npx …@latest --help` | 설치 여부가 아니라 패키지 다운로드·실행 여부를 확인 — 그 자체가 재다운로드 | 설치 결과 파일(`~/.claude/commands/gsd-help.md`) 존재로 검증 |
| 4 | GSD 패키지가 모호 — 원본 `get-shit-done-cc`(gsd-build)와 `@opengsd/gsd-core`(open-gsd)가 공존 | 다른 것을 설치할 수 있음 | 저장소 URL·버전을 명시 |
| 5 | GSD 전역 설치가 `~/.claude/commands`에 파일을 씀 | "덮어쓰기 금지" 제약과 충돌 가능 | 설치 전 이름 충돌 목록 확인 → 충돌 시 중단·보고 |
| 6 | Node 버전 미달 시 행동 없음 | 이후 단계가 애매하게 실패 | "미달이면 중단·보고" 명시 |
| 7 | 입력(기술 스택·목표)이 어느 단계에서도 쓰이지 않음 | 목표와 무관한 스킬까지 일괄 설치 | 목표에 맞는 것만 고르는 0단계 추가, 또는 입력 삭제 |
| 8 | "5종"인데 검증은 "4종" | 혼동 | GSD는 명령 세트라 별도 검증임을 명시 |
| 9 | agent-browser CLI의 "사용할 예정이면" 조건이 판단 기준 없음 | 크로미움 전역 다운로드(수백 MB)가 습관적으로 실행됨 | 별도 선택 단계로 분리, 사용 목적이 있을 때만 |
| 10 | 보고 언어·형식 미지정 | | Nexus는 한국어(korean_style.md) |

## 4. Nexus 적용 판정 — 5종별 목적·근거
**전제(하드 제약)**: CLAUDE.md §2 'Firewall'은 로컬 터미널 설치 제안을 금지하고 Nexus는 클라우드 전용이다.
따라서 이 프롬프트를 그대로(로컬 `npx`·`npm -g`·전역 설치) 실행하지 않는다. 도구 반입은 `.claude/rules/tooling.md`
방식 — 승인 → 저장소 `.claude/skills/<이름>/`에 원문 무수정 복사 + `SOURCE.md` — 으로만 한다.

| 요소 | 하는 일 | Nexus 판정 | 근거 |
|---|---|---|---|
| **mcp-builder** (anthropics/skills) | MCP 서버를 설계·구현하는 절차 안내서 | **조건부 도입 — 필요 시점에 반입** | Nexus는 이미 MCP(`.mcp.json` — Graft)를 쓴다. Snowflake 마트·일별 브리프를 Claude가 읽기 전용으로 조회하는 서버를 만들 때 쓸모가 있다. 문서형 스킬이라 실행 코드·키가 없어 위험이 낮다. 그 서버를 만들기로 하기 전에는 쓰이지 않는다 |
| **agent-browser** (vercel-labs) | Claude가 헤드리스 브라우저로 웹 페이지를 열고 클릭·캡처 | **조건부 — 검증 전용, 수집 금지** | 수집은 Scrapling(A-292)과 공식 API가 맡는다. 쓸모는 ①JS로 그려지는 페이지의 사람 확인 대체(예: 거래소 정산가 확인, DQ-30) ②발행된 HTML 브리프의 화면 점검. 다만 크로미움 설치가 필요해 Actions에서만 가능하고, 약관상 차단 도메인(Reuters·AP·Investing.com·CME·ICE)은 브라우저로도 접근하지 않는다 |
| **find-skills** (vercel-labs/skills) | 스킬 마켓에서 필요한 스킬을 검색·설치 | **미도입** | Nexus는 승인된 도구만 쓰는 고정 정책(tooling.md). 자동 탐색·설치는 승인 절차를 우회한다. 새 도구가 필요하면 그때 사람이 검토한다 |
| **design-taste-frontend** (Leonxlnx/taste-skill) | React·Next 등 웹 화면의 디자인 품질 지침 | **미도입** | Nexus 산출물은 데이터 파이프라인과 브리프다. 배포 형식도 Power BI + 데이터 계약 우선으로 정해졌다(R-026). 웹 프론트엔드가 없다 |
| **GSD** (Get Shit Done) | 계획→실행→검증 단계를 명령 세트로 관리, 자체 계획 파일 생성 | **미도입** | Nexus는 이미 작업 기록 체계(WBS·decision_queue·memory_archive)·에이전트 라우팅(skills/INDEX.md)·Plan Mode 휴먼 게이트·Karpathy 지침이 있다. GSD는 같은 역할의 두 번째 기록 체계를 만들고 전역 명령 파일을 쓴다 — 기록 분산·규칙 충돌 |

**결론**: 지금 반드시 필요한 것은 없다. mcp-builder와 agent-browser는 쓰임새가 생길 때 승인 후 반입한다(DQ-36).

## 5. Nexus용으로 고친 프롬프트 (반입 승인 후 사용)
```
#역할: Nexus 저장소에 승인된 스킬을 반입하고 검증하는 담당.
#전제: CLAUDE.md §2(로컬 설치 금지·클라우드 전용)와 .claude/rules/tooling.md가 이 지침보다 우선한다.
#입력: 반입할 스킬 이름과 쓰임새 한 문장(승인된 DQ 번호 포함).
#작업:
0. 쓰임새가 승인 범위에 맞지 않으면 중단하고 보고한다.
1. .claude/skills/<이름>/ 이 이미 있으면 SOURCE.md의 커밋만 보고하고 끝낸다.
2. 없으면 원 저장소의 고정 커밋에서 스킬 폴더를 원문 그대로 복사하고 SOURCE.md(저장소·커밋·라이선스·반입일)를 쓴다.
   (예: anthropics/skills 의 skills/mcp-builder) — 전역 설치·npm -g·@latest 금지.
3. 검증: 폴더와 SKILL.md 존재, SOURCE.md 커밋이 원 저장소에 실재, 기존 파일 변경 0건(git diff --stat).
4. tooling.md 표에 한 줄 추가, memory_archive에 C- 행 기록, 한국어로 3줄 이내 사용법을 남긴다.
#제약: 기존 파일 덮어쓰기·삭제 금지, .env 등 비밀 파일 열람 금지, 원본 스킬 수정 금지.
#실패 시: 완료로 보고하지 않는다 — 실패 명령·원인·다음 조치를 적는다.
```
agent-browser를 쓰기로 하면 위 절차에 더해, Actions 잡에서만 `agent-browser@0.39.1` 설치·브라우저 다운로드를 하고
대상 도메인을 `config/crawl_sources.yaml` allow 목록으로 제한한다.
