# 산출물 표현 방식 — 동적·직관적 템플릿 후보 비교와 선택 (2026-11-20)

> 요청(승인자): 정적 PDF·HTML 대신, 참고 이미지(① 어두운 트레이딩 터미널 — 캔들·호가창형 패널·콘솔·3D 표면 ② 3D 지식 그래프)처럼
> 동적이고 직관적인 표현을 Obsidian·Claude Code·n8n 조합으로 비교해 가장 알맞은 것을 골라 적용.
> 선정 기준: ①오프라인·현장 시연에서도 깨지지 않음 ②n8n 파이프라인이 매 실행 자동 생성 ③실무 정보(범위·적중률·경보)를 한 화면에
> ④도입 부담(서버·계정·유지 상태) 최소.

## 2. 적용 결과 — 세 도구의 역할 분담

| 도구 | 역할 |
|---|---|
| **n8n** | '00 시연'·'04 통합' 마지막 단계(실행 보고)에서 터미널을 매번 새로 생성 → 최신 데이터·파이프라인 상태가 항상 반영 |
| **Nexus Terminal**(`reports/terminal/nexus_terminal.html`) | 머리띠(기준일·정산가·파이프라인 판정·시세 띠) · 정산가 캔들 + B4a′ 범위 부채꼴(1일·1주·1개월·3개월) · 참고 범위 래더(호가창 형식, 과거 적중률·이탈률) · G1 핵심 변인·경보 · 모델 평가 보드(지표 읽는 법 포함) · 파이프라인 콘솔(단계별 성패·Codex 검증 집계) · 해상 경로 상태 · **범위 기간구조 3D 표면**(날짜×지평×80% 폭) · **온톨로지 3D 그래프**(인과 사슬·용어) · 일별 비정형 신호 |
| **Obsidian 볼트** | 온톨로지 MOC·캔버스·그래프 색 그룹·노트 템플릿 + 문서 카드. 홈에서 터미널 사본으로 바로 연결 |
| **AI 코딩 도구** | 생성기·템플릿 작성과 단계별 교차검증 자동화(산출물에는 흔적 없음) |

## 3. 시연 동선(런북 반영)
n8n '00 시연' 실행 → 끝나면 터미널 새로고침(기준일·콘솔 시각이 방금으로 바뀜) → 3개월 탭에서 범위 부채꼴·래더 → 모델 평가 보드(지표 읽는 법) → 3D 표면 회전 → 온톨로지 3D → Obsidian 캔버스.
